# Ask Mode Rules

Project contains Python educational examples. Use clear explanations with code examples.

## Text Formatting Reference
Use these formats when user requests:

### TJ1 Format
```
#-------------------------------- [Title] ----------------------------
Sr.No.           Function & Description 
----------------------------------------------------------------------
1                          function.name()
                      Description of the function.
----------------------------------------------------------
```

### TJ2 Format
```
#-------------------------------- [Title] ----------------------------
Python Expression           Results                         Description
----------------------------------------------------------------------
[1, 2, 3] + [4, 5, 6]       [1, 2, 3, 4, 5, 6]              Concatenation
```
